# موقع شركة الريان لصيانة وتنظيف الأفران بجدة

هذه نسخة مستقلة معدة للنشر، بألوان الأسود والذهبي الفاتح، باستخدام الشعار وصور الأفران المتاحة في الملفات.
- رقم الاتصال وواتساب: 0560349982
- لا يحتوي الموقع على TikTok Pixel أو Events API أو Access Tokens أو أي إعدادات تتبع من موقع الرواد.
- لا يتطلب خادمًا خاصًا أو عملية بناء: ملف index.html ومجلد assets فقط.
- موقع الرواد ومستودعه الأصلي لم يتم تعديلهما بواسطة هذه الحزمة.

## نشر على GitHub + Render
1. إنشاء مستودع GitHub جديد بالاسم alrayyan-ovens-jeddah (إذا كان متاحًا).
2. رفع index.html ومجلد assets إلى جذر المستودع الجديد، بدون تعديل مستودع الرواد.
3. في Render: New > Static Site؛ اختر المستودع الجديد والفرع main.
4. إعدادات النشر: Build Command فارغ، Publish Directory: .
5. بعد النشر اختبر عرض الصفحة على الجوال والكمبيوتر وأزرار اتصال وواتساب.

صور قبل/بعد ضمن المواد المقدمة للتصميم، ولا تدل وحدها على توثيق عمليات حقيقية.
